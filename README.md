# Jimuqu Skills

[![skills.sh](https://skills.sh/b/chengliang4810/jimuqu-skills)](https://skills.sh/chengliang4810/jimuqu-skills)

jimuqu-admin 项目的 Agent Skills 集合，为 Claude Code / Codex / Augment 等 AI 编码助手提供专业的框架和库使用指导。

## 技能列表

| 技能 | 说明 |
|------|------|
| **solon** | Solon 框架开发、迁移、调试 |
| **solon-ai** | Solon AI（ChatModel/RAG/MCP/Agent/Flow） |
| **xbatis** | Xbatis ORM（QueryChain/UpdateChain/条件注解） |
| **autotable** | AutoTable 自动建表/改表/迁移 |
| **sa-token** | Sa-Token 认证授权（登录/权限/SSO/签名） |
| **hutool** | Hutool 工具库（字符串/日期/Bean/加密/HTTP/集合） |
| **fastexcel** | FastExcel 导入导出（模板/转换器/下拉框/大数据） |
| **x-file-storage** | x-file-storage 文件存储（上传/删除/预签名/分片） |
| **justauth** | JustAuth 第三方登录（OAuth/多provider/自定义） |
| **sms4j** | sms4j 短信服务（发送/限频/多provider/模板） |
| **jimuqu-admin-dev** | jimuqu-admin 项目开发规范 |

## 安装

### Claude Code
```bash
npx skills add chengliang4810/jimuqu-skills
```

### 手动安装
将 `skills/` 目录下的技能文件夹复制到 `~/.claude/skills/` 即可。
